# Apresentação BoaPauta

Abra `index.html` no Chrome ou no Edge (duplo clique). Funciona sem internet; com internet, usa a fonte Inter.

| Tecla / gesto | O que faz |
|---|---|
| → espaço, Enter, toque na borda direita, deslizar para a esquerda | próximo slide |
| ← toque na borda esquerda, deslizar para a direita | slide anterior |
| F | tela cheia |
| N | mostra as notas de fala do slide |
| clique no vídeo | pausa ou retoma |
| toque num bloco (slide 9) | abre o detalhe da arquitetura |

- Os vídeos (`videos/`) foram gravados no app rodando de verdade; nas esperas da IA, a velocidade foi acelerada 4×, sem cortar conteúdo.
- Os números ficam no bloco `DADOS`, no começo do `<script>` de `index.html`.
- A capa usa os criativos de `../img/historico/`: copie a pasta `docs/` inteira, não só `apresentacao/`.
- `playbook_exemplo.html` é o playbook real gerado para a semana de 23/11.
